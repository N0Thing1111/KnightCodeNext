1. Programming logic: choose one of two alternatives

An if statement can perform an optional action. An if/else statement chooses between two alternatives. When the condition is true, the if body runs; otherwise, the else body runs. For a single if/else decision, the two bodies do not both run.

Plan the question, the action for true, and the action for false. Then identify any steps that belong after either outcome.

2. Express the two branches in Python

Python example - use the Python editor, not the game terminal

height = int(input())
minimum = 120
if height >= minimum:
    print("Ready")
    print(height - minimum)
else:
    print("Too short")

Example inputs, in order (one answer per input request)

130

Output

Ready
10

This ride-height example prints Ready and the centimetres above the minimum when the requirement is met. Otherwise it prints Too short. else: aligns with if and has no additional condition. Its body is also indented four spaces. The two prints in the first body belong to the same branch.

3. Equality is a decision you must make

At height 120, height >= minimum is true. Output is Ready followed by 0. Changing >= to > would wrongly reject someone exactly at the minimum. The syntax could be valid while the rule was wrong.

Test 119, 120 and 121, explaining the branch for each. In an affordability problem, the boundary is exactly the price: enough money includes the exact amount, even if nothing remains afterward.

4. Keep branch-specific work inside its branch

The difference calculation belongs with Ready. If its print moved below the whole if/else, it would also print a negative number after Too short. That would not match the stated output. Aligning a line with if means it runs after either branch; indenting it chooses which branch owns it.

Predict: for input 119, which lines run?

The comparison is false. Skip both prints under if, execute the print under else, and finish. Output only Too short.

5. Connect the two branches to a game route

Choosing numerical outcomes and choosing routes use the same structure. The game supplies can() and blocked(); those names are not built into the Python activity editor. can(right) asks whether movement right is possible; blocked(right) asks whether it is blocked. A true blocked check means you should consider a different route, not move into the obstacle.

Imagine a practice junction. Moving right is our preferred route when it is open. If right is blocked, we have already checked the map and know that up is an available alternative. These assumptions are part of the example.

KnightCode example - a small practice situation, not a full level solution

if can(right):
    move(right)
else:
    move(up)

Right open gives true, so the right move runs and the else block is skipped. Right blocked gives false, so the up move runs instead. One branch is selected, not both.

else: lines up with if. Each movement is indented underneath its own branch. The layout tells you which result selects which instructions.

6. Else is an alternative, not a safety check

Suppose both right and up are blocked. The condition is false, so the example selects move(up). But choosing that line does not make the movement possible. The else branch does not secretly test up.

For a real room, use a known-safe alternative or check the alternative too. One way to check it is a decision inside the else block:

KnightCode example - a small practice situation, not a full level solution

if can(right):
    move(right)
else:
    if can(up):
        move(up)

This is a nested decision: a decision inside another decision. If both directions are blocked, neither movement runs. Read the spaces carefully: the up move belongs to the inner check, and the entire inner check belongs to else.

You do not need nesting for every puzzle. Use it only when the plan needs another question.

7. Practise decisions in your levels

  • Right or Up?: state which direction your decision prefers and why that helps the route.

A condition tests a local fact. It does not tell you whether a direction eventually reaches the exit. After choosing a branch, continue tracing the rest of the room.
